# 配色工坊 · 生活调色盘

> 拍一张生活里的图，30 秒得到一套能直接用的配色。能预览、能检查、能带走，不需要注册。

「配色工坊」是 2026 Qoder 高校创造力大赛 **LifeHack 生活娱乐**赛道的参赛作品。它把「生活里的小配色决定」变成一个可玩、可用的网页工具：图片取色 → 场景化生成 → 实时预览 → 无障碍检查 → 导出成品。v2 共 26 项功能，覆盖工作台、专业工具、生活任务、每日内容与案例课堂。

- 纯前端、零后端、零上传：图片只在浏览器里用 canvas 处理。
- 离线可用：Service Worker 缓存整站静态资源，PWA 可安装到桌面。
- 无障碍不是弹窗式检查，而是生成时的约束：文字/背景 ≥ 4.5:1，严格模式彩色也 ≥ 3:1，并检查三种色弱模拟。

## 设计决策

- **OKLab / OKLCH 为内部色彩空间**：HSL 的明度不感知均匀，随机取样会得到「看起来差不多」的颜色；OKLCH 让亮度、彩度、色相独立可调，色域裁剪时保持色相。
- **ΔE2000 而不是 RGB 距离**：判断两个颜色是否「真的不一样」时，RGB 欧氏距离会把深蓝和深紫判得很近；ΔE2000 更贴近人眼。
- **生成器 = 带约束的采样 + 排序**：固定随机种子（可复现），每个角色在 OKLCH 范围里采样，按对比度、色差分离度、场景先验评分，三套方案之间再做一次最小色差筛选。
- **深色成对不是简单反转**：背景 / 面板 / 文字独立取 L 阶，彩色抬亮后同时保证与背景 ≥ 3:1、深色文字在强调色上 ≥ 4.5:1。
- **色弱友好是硬约束**：protan / deutan / tritan 三种模拟下，主 / 辅 / 强调两两 ΔE ≥ 8；无解时返回最接近解并标记。
- **修复对比度保持色相**：在 L/C 网格上搜索，取 ΔE2000 最小的达标解，而不是直接压成黑白。
- **单 bundle**：不动态拆包，保证 `配色工坊-免安装.html` 能内联；二维码库体积约 10 KB gzip，整体仍在 120 KB 预算内。
- **离线缓存的坑**：Vite 产物带 `crossorigin`，请求会带 `Origin`，而安装时预缓存的请求没有；响应头 `Vary: Origin` 会让 `caches.match` 全部落空。因此匹配时必须 `ignoreVary: true`。

## 数据与隐私

没有账号、后端与统计脚本。收藏、历史、设置、每日连续天数与挑战最佳成绩在 `localStorage`（`cf.v2`，自动迁移旧 `cf.v1`）；图片只存在于当前标签页内存，刷新即释放。分享链接把配色编码进 URL 片段，不上传服务器。方案库备份由用户主动导出，不自动上传。

## 已知限制

- 屏幕吸管依赖 `EyeDropper`，Safari 不支持，会提示改用上传截图；摄像头需要 HTTPS 或 localhost。
- 分享链接较长（未压缩），超长方案可能触及部分平台的 URL 长度限制；分享卡二维码指向同一条链接。
- 单文件版用 `file://` 打开时，分享链接是本机路径，对方无法直接打开；正式分享请用部署后的网址。
- 贺卡 / 打印 / 周历等画布成品依赖系统字体，不同系统字形会略有差异。
- 不做色彩人格测试、AI 生成、账号云同步、图像分割/AR 换色与多人协作。
