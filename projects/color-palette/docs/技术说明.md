# 配色工坊 · 技术说明（v2）

## 一句话

输入一张生活照片、一个颜色或一个主题，输出可直接落地的配色、视觉预览、无障碍报告与成品文件；全部在浏览器里完成，无后端、无上传。

## 要解决的问题

生活里大量小决策都卡在「配什么颜色」：今天穿什么、房间刷什么色、手账怎么排、朋友圈封面用什么调、贺卡送什么感觉。专业配色工具要么面向设计师，要么只给随机色板，不解决「这张照片适合什么颜色」「这个颜色能不能看清」「怎么变成能发出去的成品」。

v2 把链路拆成四段，并各自做深：

1. **取材**：图片、屏幕吸管、摄像头、多图情绪板、CSS/JSON 导入、每日/主题/案例预设。
2. **生成**：场景化采样 + 约束（对比度、色差、色弱、深色成对）+ 单色微调。
3. **验证**：WCAG 2.2、APCA、色弱分离、CMYK 近似、场景用法。
4. **带走**：CSS/JSON/SVG/PNG、9 种设计令牌、分享卡、周历、房间清单、贺卡、打印页。

## 技术方案

### 1. 感知均匀的色彩计算

- 内部统一 OKLab / OKLCH；输入兼容 HEX / RGB / HSL，输出统一 HEX。
- 和谐关系在 OKLCH 色相环上计算，明度与彩度独立处理。
- 超出 sRGB 色域时保持 L 与 h，二分收缩彩度。
- 色差用 CIEDE2000；对比度用 WCAG 2.2 相对亮度；另给 APCA Lc。

### 2. 带约束的生成器

- 固定随机种子（mulberry32），同一输入可复现。
- 每个角色在人体工学区间采样，场景 / 风格 / 情绪对色相、彩度、明度做有界修正。
- 评分包含：文字/背景对比度、彩色/背景对比度、角色间 ΔE2000 分离度、场景先验。
- 三套方案之间做最小 ΔE 筛选，避免同质化。
- 严格模式：文字 ≥ 4.5、彩色 ≥ 3 是硬约束。
- 一键修复：固定背景，在保持色相的 L/C 网格上搜索 ΔE2000 最小的达标解。

### 3. 深色成对与色弱安全

- **深色成对**：背景 / 面板 / 文字独立取 L 阶；主 / 辅 / 强调抬亮后，先保证与深色背景 ≥ 3:1，再保证深色文字在强调色上 ≥ 4.5:1。结果随 share payload v2、JSON、CSS 的 `[data-theme="dark"]` 一起导出。
- **色弱安全**：Machado 2009 矩阵模拟 protan / deutan / tritan；约束主 / 辅 / 强调两两 ΔE ≥ 8。无解时返回最接近解并标记 `safe:false`，界面显示三组分离度。

### 4. 取材

- **图片**：缩放到 ≤160px，OKLab k-means++（k=8，14 轮），按「占比 0.6 + 彩度 0.4」排序，合并 ΔE < 6 的近似色。
- **屏幕吸管**：`EyeDropper` API；不支持或取消时给出提示，不阻塞其它取材方式。
- **摄像头**：`getUserMedia` 后置摄像头，每 300ms 把视频帧缩到 64px 提取 5 色；快门把整帧转 JPEG 走图片流程；关闭即 `stopTracks`；区分权限 / 非 HTTPS / 无设备 / 不支持。
- **情绪板**：2–6 张图各自缩到 96px 提取 5 色，合并后按 ΔE 去重取 8 色，避免大图内存峰值。
- **导入**：解析 HEX 列表、CSS 变量、设计令牌 JSON；按彩度/明度把颜色映射到 6 个角色，不足 6 色时补默认并提示。

### 5. 专业工具

- **色阶**：OKLCH 中 L 从 0.97 到 0.12 等距下降，C 中段最高，H 不变，生成 11 档；语义色固定色相锚点，并保证在背景上 ≥ 4.5:1。
- **设计令牌**：CSS、Tailwind `@theme`、W3C/Figma Tokens、Android XML、iOS Swift、Flutter Dart。
- **渐变**：线性 / 径向 / 锥形；2–4 个色标；按每个停靠点计算白/黑文字的最低对比度，给出建议；Canvas 导出 1200×800。
- **CMYK**：标准公式近似，明确标注「仅供打样参考」。

### 6. 生活任务与画布成品

- 周历 1080×1920：7 天 × 上装/下装/鞋包 + 建议。
- 房间清单 A4 1240×1754：5 个部位按 45/25/15/10/5 分配，房间示意图 + 面积表。
- 贺卡 1080×1440：五种版式（经典/极简/杂志/渐变/胶片）+ 独立调色 + 场合标题 + 收礼人 + 祝福，实时 canvas 预览。
- 打印页 A4/A5 150dpi：色卡或房间清单，带裁切线、CMYK 注。
- 分享卡：3:4 / 9:16 / 16:9，浅/深，标题/副标题/日期可编辑，二维码使用 `qrcode-generator`，导出 PNG；`navigator.share` 支持时直接调系统分享。

### 7. 每日 / 挑战 / 内容

- 每日：日期字符串 FNV-1a → 种子 → 基础色相、场景、和谐关系；文案按种子取；`visitDaily` 维护连续天数与 7 天归档。
- 挑战：四种题型——找色相（4–6 选 1，色相步长 5–14°）、排明度（5–7 块，OKLab 明度差 0.024–0.046）、找不同（6–8 块，色相偏 4–12° 或饱和度偏 12–18）、对比度（4–5 组，只有一组达到 3 / 4.5 / 7 阈值）；60 秒 10 题，难度随题号收窄；每轮把轮次混入随机种子，选项数从 4–6 / 5–7 / 6–8 递增，排明度有正反两个方向，找不同分色相/饱和度两种变体，对比度阈值取 3 / 4.5 / 7；得分 = 10 + 时间奖励；最佳成绩存 `cf.v2`；做题中切换题型会立即重置比分、计时与题号，以新题型重新开始。
- 主题：12 节气 + 8 城市 + 盲盒；预设 → 稳定方案，缓存避免重复生成。
- 案例：8 个场景；课堂：60-30-10、对比度两篇，含示例与要点。

### 8. 页面层级与导航

- 顶部主导航固定 5 项：首页 / 工作台 / 每日 / 工具 / 我的；进入工具子页时「工具」保持高亮。
- 所有非首页路由由 `PageNav` 统一渲染「返回上一级」与面包屑；工具子页返回 `/tools`，工作台/每日/我的/关于返回首页。
- 工具中心按使用顺序分为「开始与素材、专业工具、生活任务、灵感与学习、每日与挑战」，避免把所有入口平铺。
- 返回是确定的父级链接，不依赖浏览器 history，分享链接/直接打开也有稳定层级。

### 9. 工程与状态

- Vite + TypeScript + Preact + signals；纯 CSS 设计令牌；无 UI 框架、无外部字体、无统计脚本。
- 状态集中在 `src/state.ts`，派生出 `daily` / `challenge` / `toolDrafts`；localStorage schema v2（`cf.v2`），读取时兼容迁移 `cf.v1`，不删除旧 key。
- 分享：base64url 紧凑 JSON，v2 增加 `d`（深色）字段；解码兼容 v1。
- 路由：hash 路由，16 个页面；采集/分享卡等以原生 `<dialog>` 覆盖在工作台上。
- Service Worker：预缓存 `index.html` 并从 HTML 解析带 hash 的 JS/CSS；`ignoreVary: true` 解决 `crossorigin` 与 `Vary: Origin` 导致的离线失效；PWA manifest 使用相对 `start_url` / `scope`。

## 视觉系统

- 参考 LuoStratus.cn：纯黑 `#000` 底色、靛蓝 `#4a55e6` 强调、800 字重粗标题、等宽大写小标签（`.eyebrow`）与 16px 圆角深色卡片。
- 首页主视觉用浏览器窗口框（三色圆点 + 调色板网格 + `LIVE PREVIEW` 状态条）替代普通插画；强调字用靛蓝渐变。
- 默认深色并写入一次性 `cf.ui.v3` 标记，保证老用户首次升级也看到新皮肤；右上角仍可切浅色，浅色保留同一套几何与靛蓝强调。
- 所有工具页的强调色、卡片、按钮、导航统一走 CSS 令牌；工作台预览里的手机/网页仍是“真实内容”，不强制深色。

## 已知取舍

- 生成器是「规则 + 采样 + 评分」，不是模型；确定、快、可解释，但覆盖不了极端审美需求。
- 深色成对是独立 L 阶 + 对比度约束，不是简单反转；仍以浅色方案为起点。
- 色弱安全只约束主/辅/强调，文字/背景不参与；无解时会标明。
- 单 bundle 保证免安装单文件版可内联，代价是首屏 JS 略大。
- 分享链接未压缩；极端长名称会变长。
- 画布成品依赖系统字体，跨系统字形略有差异。
- 不做账号、云同步、AI 生成、图像分割/AR、多人协作与色彩人格测试。
