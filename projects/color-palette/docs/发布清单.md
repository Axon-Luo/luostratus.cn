# 发布清单（Qoder Sites · v2）

> 比赛要求：作品用 Qoder 开发，并部署到 **Qoder Sites** 公开访问。Qoder Sites 免费版仅支持静态站点，本项目构建产物正好是纯静态 `dist/`。

## 0. 前置

- [ ] 已安装 Qoder（IDE 或 CLI）并登录自己的账号
- [ ] 已确认 Qoder Sites 可用（新建站点不报配额限制）
- [ ] 本机有 Node 18+ 与 pnpm

## 1. 构建与自检

```bash
pnpm install
pnpm check            # 类型检查 + 91 个单元测试
pnpm test:e2e         # 59 个端到端测试（需要本机 Edge）
pnpm build            # 产出 dist/
pnpm preview          # http://localhost:4173 人工过一遍
```

构建成功的判断：`dist/index.html`、`dist/assets/*.js`、`dist/assets/*.css`、`dist/sw.js`、`dist/manifest.webmanifest`、`dist/icons/*` 均存在；`pnpm preview` 下首页、工作台、分享卡都能正常用。

> v2 构建基线：JS 102.4 KB gzip、CSS 12.1 KB gzip；单测 137 / e2e 109 / axe 20 页全绿。

## 2. 发布到 Qoder Sites

**方式 A：Sites 面板（推荐）**

1. 用 Qoder 打开本仓库目录。
2. 侧边栏选择 **Sites → Add site**。
3. 选择「从现有项目发布」/把 `dist` 作为发布目录；如果 Agent 询问构建方式，回答：静态站点，发布目录 `dist`，无需服务端。
4. 先发**私有预览**，用手机扫码或链接检查一遍。
5. 打开 **Sharing**，切换为 **Public**（会有二次确认）。
6. 记录公网链接，填入作品提交页。

**方式 B：Qoder CLI**

安装并登录 Qoder CLI 后，在会话里说「把 `dist` 发布成站点」，按提示确认；或在交互式终端用 `qoder sites` 查看站点与发布状态。

> 不要自己拼发布请求；写操作（发布、公开访问）都通过 Qoder 的 Sites Skills 完成，会要求显式确认。

## 3. 发布后验证（16 个路由）

- [ ] 公网链接在**未登录的浏览器**里能打开
- [ ] 手机 4G（非 Wi-Fi）打开正常，无横向滚动
- [ ] 首页 → 今日一色 → 工作台 → 工具中心 → 我的方案 主链路可走通
- [ ] `/outfit` `/room` `/card` `/print` 四个生活任务能导出 PNG，尺寸正确
- [ ] `/scales` `/gradient` `/themes` `/cases` `/learn` `/play` `/daily` 均可打开
- [ ] 工作台：上传图片 / 屏幕吸管 / 摄像头 / 情绪板 至少两种可用
- [ ] 分享卡：3:4 下载 PNG，二维码能被手机扫开
- [ ] 分享链接复制到无痕窗口，能还原同一套配色
- [ ] PWA：Chrome/Edge 出现「安装到桌面」，安装后独立窗口可打开
- [ ] 第二次访问后开飞行模式刷新，页面仍能打开（离线）
- [ ] 浏览器控制台无报错（Service Worker 注册失败会打印，但不应影响主流程）
- [ ] 页脚、关于页信息与提交材料一致

## 5. 交付包

```bash
pnpm release          # 构建并生成「发布包/配色工坊 v2/」
cd "发布包/配色工坊 v2"
node serve.mjs        # http://localhost:4180/
```

包内结构：

- `site/`：Qoder Sites 的发布目录
- `docs/`：技术说明、发布清单、演示脚本、截图
- `配色工坊-免安装.html`：单文件版，双击可用
- `serve.mjs` / `一键打开.bat`：本地预览

## 6. 风险与回滚

| 风险 | 处理 |
| --- | --- |
| 公开访问审核未通过 | 先保持私有预览，按提示补充信息；同时保留 `dist` 压缩包作为现场演示备份 |
| Qoder Sites 配额受限 | 减少站点数量，只保留最终站点；静态资源已压缩（JS 102.4 KB gzip） |
| 发布后样式错乱 | 确认 `vite.config.ts` 的 `base: './'` 未改；清缓存/换设备复查 |
| 旧版本缓存残留 | Service Worker 缓存名已升到 `cf-cache-v5`；发布后硬刷新一次 |
| 摄像头/吸管不可用 | 属浏览器能力差异；上传截图/情绪板是等价入口，演示时准备一张照片兜底 |
| 需要回滚 | 保留每次发布的 `dist` 副本（按日期命名），在 Sites 面板恢复上一版 |
