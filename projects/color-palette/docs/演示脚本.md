# 演示视频脚本（60–90 秒 · v2）

**录制设置**：1280×800 或 1440×900 浏览器窗口；隐藏书签栏；关闭通知；提前准备一张色彩丰富的生活照（穿搭/房间/食物），并收藏一套方案。

**核心原则**：前 5 秒必须出现「照片 → 配色」的结果对比，让评委立刻知道这是什么；中段展示 v2 的成品能力，而不是只罗列功能。

| 时间 | 画面 | 旁白 / 字幕 |
| --- | --- | --- |
| 0–5s | 工作台：左边照片，右边三套配色，鼠标从照片划到色块 | 「生活里最难的不是买什么，是配什么颜色。」 |
| 5–10s | 首页标题「把生活，调成喜欢的颜色」+ 今日/工具入口 | 「配色工坊：拍一张照片，30 秒得到能直接用的配色。」 |
| 10–22s | 工作台拖入照片 → 提取主色 → 三套方案；点「摄像头/屏幕吸管」各停 2 秒 | 「图片只在本地处理。拍照、屏幕吸管、多图情绪板，都能开始。」 |
| 22–32s | 点「深色成对」「色弱友好」，检测面板出现深色对比度与色弱分离 | 「一次生成浅色和深色两套，还检查三种色弱模拟。」 |
| 32–42s | 点色块调单色 → 自动锁定 → 「让其它颜色适配」 | 「喜欢的颜色可以单独调，调完自动锁住。」 |
| 42–54s | 打开分享卡，切 9:16，改标题，下载 PNG，二维码入镜 | 「一键生成带二维码的分享卡，PNG 直接发。」 |
| 54–64s | 工具中心 → 一周穿搭，7 天卡片，导出周历 | 「穿搭、房间、贺卡、打印，四个生活任务都能出成品。」 |
| 64–72s | 每日一色 + 配色挑战，快速点两题 | 「每天一套固定配色，60 秒挑战练眼睛。」 |
| 72–80s | 主题配色：节气/城市，点一套进入工作台 | 「12 节气、8 座城市，还有随机盲盒。」 |
| 80–85s | 断网刷新，页面仍能打开；PWA 安装按钮 | 「整个工具可以离线使用，也能安装到桌面。」 |
| 85–90s | 回到首页 / Logo | 「配色工坊 · 生活调色盘。」 |

**录制提示**

- 操作节奏放慢，每次点击后停 0.5 秒再继续；后期可 1.2× 加速空镜。
- 旁白先录后配画面，避免鼠标声和键盘声。
- 导出与分享要拍到「成功提示」的 toast 或下载完成，评委能确认不是静态图。
- 摄像头在没有设备的机器上会失败；录制前先确认，或改用「情绪板」镜头。
- 如果时长紧张，删掉 64–72 秒的每日/挑战，保留分享卡与生活任务。
