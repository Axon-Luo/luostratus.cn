## 三、为什么做

- **问题来源**：生活里的配色决定频率很高，但现有工具要么是给设计师的参数面板（色环、曲线、令牌），要么要注册、要上传图片。普通人只想「拍张照，告诉我怎么搭」，这个缺口一直没人填。
- **隐私直觉**：照片是很私人的东西。所以整站纯前端：图片只在浏览器 canvas 里处理，刷新即释放；没有账号、后端与统计脚本，收藏和历史只存在本机 localStorage。
- **无障碍不该是事后弹窗**：对比度不足是「生成出来的配色不能用」的根因。我们把 WCAG 2.2 四项对比度、APCA 与三种色弱模拟做成生成时的硬约束（文字/背景 ≥ 4.5:1），不达标给「离原色最近」的一键修复，而不是生成完再警告。
- **赛道契合**：LifeHack 要的是「生活里的小hack」。一周穿搭、房间刷色、礼物贺卡、打印色卡这些任务，就是把配色决定变成可以直接带走的生活成品。

## 四、怎么用（5 步，评委照着做即可）

1. 打开作品链接，首页点「开始配色」进工作台
2. 上传 / 拖拽 / 粘贴一张照片（或点一个节气主题），自动提取主色并生成三套方案
3. 切换手机 / 网页 / 海报 / 壁纸 / 穿搭五种预览看效果；对比度或色弱检查不足时点「一键修复」
4. 单色微调、空格换一批，满意后点星标收藏
5. 导出 CSS 变量 / PNG 色卡 / 带二维码的分享卡；或进「打印色卡」选一种版式，下载 A4/A5 150dpi 打印页
