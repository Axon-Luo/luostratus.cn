## 前言

Minecraft 是我玩得最久的游戏之一。从原版生存到各种整合包，每个版本文件夹都代表一段独特的方块旅程。

截至 2026 年 7 月，我的 PCL 启动器中已安装 **20 个版本**，涵盖 Fabric、Forge、NeoForge 三大模组加载器，版本跨度从 1.19.2 到最新的 26.2（1.21.2+）。

---

## 一、原版优化向

这一类以原版体验为基础，通过 Fabric/Forge 加载优化和辅助模组，提升性能和游戏体验。

### 1.20.1-Forge 系列

| 版本 | 加载器 | 说明 |
|------|--------|------|
| `1.20.1-Forge_47.4.10` | Forge 47.4 | 主力生存档所在版本，主世界 `GNLXC_main_v1.0.1` 存档 |
| `1.20.1-Forge_47.4.20` | Forge 47.4 | 同版本更新 Forge，可能用于测试新版模组兼容性 |

1.20.1 是目前 Mod 生态最成熟的版本之一，Forge 47.4 系列支持大量经典 Mod。

### Fabric 系列

| 版本 | 加载器 |
|------|--------|
| `1.19.2-Fabric 0.19.3` | Fabric |
| `1.21.11-Fabric 0.19.3` | Fabric |
| `1.21.7-Fabric 0.19.3` | Fabric |
| `26.2-Fabric 0.19.3` | Fabric |

Fabric 以轻量和高性能著称，Sodium、Lithium 等优化模组的首选平台。从 1.19.2 到 26.2 的版本跨度说明你一直在跟进新版本。

### 26.2-Forge_65.0.1

最新版 Forge 体验，Forge 65 是面向 Minecraft 1.21.2+ 的新一代加载器，性能大幅改进。

## 二、重度整合包

这类是改变了游戏核心玩法的整合包，每个都有独立的世界观和机制。

### 机械动力 1.21.1-NeoForge

```
机械动力1.21.1-NeoForge_21.1.235
```

**Create Mod**（机械动力）是近年来最受欢迎的模组之一，以齿轮、传送带、应力系统为核心的机械美学。使用 NeoForge 加载器说明这是较新的版本。Create 的核心理念是"用机械而非魔法"——每台机器都需要真实的动力传输。

### DeceasedCraft - Urban Zombie Apocalypse

```
DeceasedCraft - Urban Zombie Apocalypse
```

丧尸末日主题的硬核整合包。背景设定在城市环境中，生存压力极大——资源稀缺、尸潮汹涌。这类包通常包含枪械模组、废弃城市生成和硬核生存机制。

### Mechanomania - 航空学

```
Mechanomania-航空学
航空学
```

两个关联版本，航空主题的科技整合包。大概率围绕飞机模组（如 Create: Aeronautics、Immersive Aircraft 或 Manus 系列）构建，让你在 Minecraft 中制造和驾驶飞行器。

### 沉浸战斗 Immersive Fight 4.2.3

```
沉浸战斗Immersive Fight 4.2.3
```

以战斗系统为核心的整合包。可能包含更好的战斗动画、连击系统、闪避机制等模组，把 Minecraft 的点击式战斗转变为更有深度的动作体验。

### 乌托邦探险之旅 3.5.2

```
乌托邦探险之旅3.5.2
```

经典中式 RPG 探险整合包，以探索、地牢和 BOSS 战为主线。乌托邦系列在中文 MC 社区有相当知名度，通常包含自定义地图、剧情线和大量 RPG 元素。

### 逆转未来 1.1.4

```
逆转未来1.1.4
```

时间穿越/科幻主题的整合包，标题暗示着改变历史或未来的核心玩法。

### Closing Song / 落幕曲 1.6.4

```
Closing Song1.6.4
落幕曲1.6.4
```

同一整合包的两个版本（中英文命名），1.6.4 可能指 Minecraft 版本或包本身的版本。以"终曲"为主题的叙事向整合包，可能带有剧情驱动的冒险体验。

## 三、专项优化与定制

### 红石生电优化

```
红石生电优化【Redstone Survival Optimization】
```

专为红石和生电（生存电力）玩法优化的版本。这类整合包通常包含：
- **Carpet Mod** 系列：精准控制游戏机制
- **Lithium / Phosphor**：服务端优化
- **Litematica**：建筑蓝图
- **MiniHUD / Tweakeroo**：信息显示和微调

红石科技玩家对 TPS（每秒 tick）要求极高，这类优化包在大型红石机器运行时至关重要。

### 天气优化 1.21.11

```
天气优化1.21.11
```

针对天气系统和视觉效果的优化版本，可能包含更好的云、动态天气、光影支持等。

### 你好，新蒸程 V1.5.9

```
你好，新蒸程V1.5.9
```

"蒸汽"暗示与 Create 或蒸汽朋克主题相关。这是一个以机械和工程为核心的整合包。"新蒸程"谐音"新征程"，版本号 V1.5.9 说明已迭代多次。

### 1.21.11狐

```
1.21.11狐
```

以"狐"命名的版本，可能是某个自定义整合或朋友推荐的包名。

## 关于 PCL

所有版本都通过 **PCL**（Plain Craft Launcher，简洁启动器）管理。PCL 是目前中文 MC 社区最受欢迎的第三方启动器之一，它本身不带 mod，但集成了：

- 多版本独立管理
- 模组/整合包一键下载
- 资源包与光影管理
- 快速调试与日志查看
- 快照版支持（如我使用的 `PCL+快照版+2.12.8.0`）

相比官方启动器，PCL 的版本隔离和快速切换更适合同时维护 20 个版本的玩家。
